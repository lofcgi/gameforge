# 아트 디렉션 (dune-rover)

- 기준 해상도 320x180, 정수배 확대, nearest.
- 팔레트: design/palette.json 16색 (어두운 남색 밤 + 모래 노랑·벽돌 주황 + 청록 포인트). 분홍·보라는 쓰지 않는다 → 생성 배경색은 마젠타 #FF00FF.
