# AI 에이전트로 게임 하네스 만들기

> 문서 유형: 개요

이 자료를 읽으면 AI 코딩 에이전트에게 "만들어 줘"라고 말하는 수준을 넘어, 에이전트가 스스로 실행하고 확인하며 일하도록 틀을 짜는 방법을 배울 수 있어요. 교재는 이 저장소 자체예요. 하네스 gameforge(`harness/`)와 그것으로 만든 2D 픽셀 낚시 게임 cat-angler(`games/cat-angler/`)를 어떻게 만들었는지, 잘된 것과 반려당한 것을 함께 다뤄요.

## 이 자료가 맞는 사람

- Claude Code 같은 코딩 에이전트를 써 봤고, 더 큰 결과물(게임, 도구, 파이프라인)을 맡기고 싶은 개발자
- 코드를 직접 쓰지 않지만 에이전트와 함께 게임이나 창작물을 만들고 싶은 기획자, 디자이너

Claude Code가 무엇인지는 안다고 가정해요. 이 저장소, 게임 엔진, 이미지 생성 모델은 몰라도 돼요.

## 읽고 나면 할 수 있는 일

- 조사 결과를 "에이전트가 어길 수 없는 장치"로 바꾸는 방법을 설명할 수 있어요.
- 저장소를 내려받아 하네스로 작은 게임을 실행하고, 생성 이미지 한 장을 게임 속 픽셀 캐릭터로 바꿀 수 있어요.
- 여러 에이전트에게 일을 나눠 줄 때 계약 문서와 작업 지시서를 쓸 수 있어요.
- 에이전트가 "됐다"고 말할 때 무엇으로 확인해야 하는지 고를 수 있어요.

## 실습 준비물

읽기만 한다면 준비물이 없어요. [튜토리얼](tutorials/first-game.md)을 따라 하려면 아래가 필요해요. 저장소가 확인한 환경은 macOS예요(`harness/README.md`). 다른 운영체제에서는 확인하지 않았어요.

| 도구 | 쓰는 곳 | 설치 |
|---|---|---|
| uv (Python 3.12 이상) | `gf` 실행 | `brew install uv` |
| Godot 4 | 게임 실행 | `brew install --cask godot` |
| ffmpeg | 영상 프레임, 소리 측정 | `brew install ffmpeg` |
| fal 계정과 `FAL_KEY` | 이미지·영상·소리 생성(유료 단계에서만) | https://fal.ai |

## 이 자료를 읽는 법

- **출처 표시**: 저장소 파일로 확인한 내용에는 `harness/README.md`처럼 저장소 루트 기준 경로를 붙였어요. 저장소에는 없고 작업 세션의 기록으로만 전해지는 내용은 "(세션 기록)"이라고 적었어요.
- **날짜**: 이 자료의 숫자는 2026-11-23 기준이에요. cat-angler는 그 시점에도 다듬는 중이어서 에셋 수, 비용, 심사 결과는 지금 저장소와 다를 수 있어요.
- **절대 경로**: 저장소 문서 안의 `/Users/iyeonsang/Desktop/game/...`은 처음 작업한 컴퓨터의 경로예요. 여러분이 내려받은 위치로 바꿔 읽으세요.
- **작성 기준**: 이 자료는 토스 테크니컬 라이팅 가이드를 따라 썼어요. 적용한 원칙은 [작성 기준 메모](_writing-notes.md)에 있어요.
