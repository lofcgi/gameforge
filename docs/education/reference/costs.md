# 생성 비용표

> 문서 유형: 참조

저장소에 기록된 생성 단가와 실제 지출을 모았어요. 비슷한 프로젝트의 예산을 어림할 때 쓰세요. 모든 금액은 **추정 비용**이에요. 호출 전에 단가로 계산한 값이고 fal 계정의 실제 청구액과 다를 수 있어요. 코딩 에이전트(Claude Code) 사용량은 이 표에 들어 있지 않아요.

## 읽기 전에 알아 둘 것

- 단가는 2026-11-22 기준이에요. 모델과 가격은 자주 바뀌어요. 지금 값은 `gf fal price <모델 ID>`나 `gf gen ... --dry-run`으로 확인하세요.
- 일부 모델은 단가 단위(tokens, credits, compute seconds) 때문에 비용을 미리 계산할 수 없어요. 인계 기록은 Tripo와 Seedance 호출의 실제 청구액은 fal 대시보드에서 확인해야 한다고 적어요(`.claude/handoffs/2026-11-23-gameforge-cat-angler.md`).
- 지출 합계는 각 프로젝트의 비용 기록(`.gf/ledger.jsonl`)을 2026-11-23에 직접 더한 값이에요.

## 종류별 단가

`harness/README.md`가 2026-11-22 실측으로 적은 값이에요.

| 만드는 것 | 역할 | 단가 |
|---|---|---|
| 이미지 1장 | `image.concept`, `image.edit` | $0.08 |
| 스프라이트 영상 3초 | `video.sprite` | 약 $0.34 |
| 룩 영상 4초 | `video.look` | 약 $0.9 |
| 3D 모델 1개 | `model3d.gen` | 약 $0.5 |
| 리깅 1회 | `model3d.rig` | $0.8 |
| 효과음 | `audio.sfx` | 초당 $0.002 |
| 음악 | `audio.music` | 분당 $0.6 |

## 비용 한도

| 설정 | 값 | 위치 |
|---|---|---|
| 호출당 기본 한도 | $3 | `harness/tools/gf/core/defaults.toml`의 `[budget] max_usd_per_call`. 게임 폴더의 `.gf/config.toml`이 덮어써요 |
| 명령별 한도 | `--max-usd <값>` | 설정보다 우선해요 |
| 비용을 계산할 수 없는 호출 | `--estimate-usd <값>` 또는 `--allow-unknown-cost`가 있어야 실행돼요 | `harness/AGENTS.md` |

## cat-angler의 지출

`games/cat-angler/.gf/ledger.jsonl`을 2026-11-23 오전에 더한 값이에요. 게임을 다듬는 중이라 이 문서를 쓰는 동안에도 늘고 있었어요.

| 역할 | 호출 수 | 추정 지출 |
|---|---|---|
| `image.edit` | 103 | $8.32 |
| `audio.music` | 12 | $4.00 |
| `video.sprite` | 1 | $0.34 |
| `image.concept` | 1 | $0.08 |
| `audio.sfx` | 39 | $0.06 |
| 합계 | 156 | $12.80 |

이미지의 대부분이 `image.edit`인 이유는 기준이 되는 그림 한 장을 참조로 주고 다른 자세와 대상을 만들었기 때문이에요. 그래야 같은 캐릭터와 같은 화풍이 유지돼요.

인계 기록에 남은 다른 숫자예요. 비용 기록의 합과 일치하지 않고, 차이를 설명하는 기록은 저장소에서 찾지 못했어요.

| 인계 기록의 문장 | 시점 |
|---|---|
| "fal 추정 누적 약 $9 (하네스 시험 약 $8, cat-angler 약 $0.7)" | 그레이박스까지 |
| "cat-angler 데모 전체의 생성 비용은 $13~17로 가늠했다" | 재제작 전의 예상 |
| "cat-angler 누적 생성 비용 약 $16" | 재제작 뒤 |

인계 기록은 fal 잔액이 작업 중에 두 번 바닥났고 사용자가 두 번 충전했다고도 적어요.

## 조사에서 본 다른 사람들의 비용

최종 조사 보고서는 다른 1인 제작자들의 비용을 **자가 보고** 기준으로 8시간·약 550달러부터 15주·약 1,100~1,150달러까지라고 적어요. 보고서의 표를 보면 이 값은 주로 코딩 에이전트의 토큰·구독 비용이고, 독립적으로 검증되지 않았어요. 위 표의 생성 비용과 직접 비교할 수 없어요.
