# plan: 구현 전에 결정을 닫는다

문서의 양은 중요하지 않다. **구현을 시작하기 전에 설계 결정이 닫혔는가**가 중요하다. 설계가 정해지기 전에 만든 것은 버리게 된다.

## 명령

`$GF` = `uv run -q --project "${CLAUDE_PLUGIN_ROOT}/tools" gf --project "<게임 폴더 절대 경로>"`.
공통 규약: `${CLAUDE_PLUGIN_ROOT}/skills/gf-start/conventions.md` (이 세션에서 아직 안 읽었으면 먼저 읽는다).

## 1. 묻는다 (한 번에, 최대 다섯 개)

이미 들은 것은 다시 묻지 않는다. 답이 없으면 추천안을 내고 "이대로 갈까요?"로 닫는다.

1. 플레이어는 **무엇을 하는가** (동사 하나: 뛴다, 쏜다, 쌓는다, 피한다, 운전한다)
2. 왜 한 판 더 하고 싶은가 (기록, 다음 레벨, 다른 빌드, 분위기)
3. 한 판은 얼마나 긴가, 어떻게 이기고 지는가
4. 꼭 있어야 하는 것 한두 가지, 절대 원하지 않는 것
5. 얼마나 걸려서 누구에게 보여 줄 것인가 (주말 프로토타입 / 몇 주짜리 데모)

사용자가 기존 게임 이름을 대면: 그 게임을 다시 만들지는 않는다고 말하고, 그 게임에서 좋아하는 **특성**(속도, 카메라, 색, 긴장감)을 세 개쯤 말로 뽑는다. 이름·캐릭터·레벨·화면 구성은 가져오지 않는다.

## 2. 범위를 약점에 비춰 본다

`$GF state show` 로 엔진·차원·스타일을 확인하고 아래에 걸리는 것이 있으면 대안과 함께 말한다. 사용자가 고집하면 그대로 하되 `brief.md` 의 "위험" 에 적는다.

| 걸리는 것 | 왜 | 대안 |
|---|---|---|
| 가까이서 보는 3D 인물, 대화 장면, 얼굴 | 모델·리그·애니메이션이 가장 약하다. 가까이서 보면 어색하다 | 원거리·고정 카메라, 탈것·로봇·생물 주인공, 2D |
| 넓은 오픈 월드, 많은 레벨 | 내용이 얇아져 "빈 숲 걷기"가 된다 | 화면 한두 개 크기의 레벨 하나를 끝까지 |
| 여러 시스템(제작 + 전투 + 대화 + 경제) | 봇이 균형을 못 잡고 사람 플레이 시간이 모자란다 | 핵심 동사 하나, 보조 시스템 하나 |
| 온라인 멀티플레이, 계정, 결제 | 하네스가 검증할 수 없다 | 로컬 한 명 |
| 정밀한 애니메이션이 핵심인 격투·댄스 | 프레임 단위 애니메이션 품질이 필요하다 | 판정이 단순한 액션 |

잘 되는 쪽: 분위기·속도감·아름다움 중심, 스타일이 뚜렷한 그림, 짧은 한 판.

## 3. `design/brief.md` 를 쓴다

한 화면에 들어오는 길이(60줄 안쪽)로, `${CLAUDE_SKILL_DIR}/brief-template.md` 의 틀을 따른다. 빈칸을 남기지 않는다. 정하지 못한 것은 "미정"으로 두지 말고 사용자에게 물어 닫는다.

반드시 들어가는 것:

- **한 문장 훅**: "〈누가〉 〈어디서〉 〈무엇을 해서〉 〈무엇을 얻는〉 게임." 듣고 화면이 떠올라야 한다.
- **핵심 루프**: 시작 → 플레이 → 이김/짐 → 재시작이 몇 초·몇 분 단위인지.
- **Keep**: 끝까지 지킬 것 3~5개. **Avoid**: 하지 않을 것. **Out of scope**: 이번에는 안 만드는 것(만들고 싶어질 때 여기를 가리킨다).
- **닫힌 결정**: 카메라, 조작 키, 화면 비율, 한 판 길이, 레벨 수. 구현 중에 바꾸려면 사용자에게 다시 묻는다.
- **사람이 판정할 것**: 재미, 조작감, 소리. 에이전트가 숫자로 볼 수 없는 것들과 그것을 언제 물을지.
- **인수 기준**: 그레이박스가 끝났다고 말할 수 있는 조건 3~5개. 실행해서 확인할 수 있는 문장으로 쓴다 (예: "봇이 레벨을 30초 안에 깬다", "죽으면 2초 안에 다시 시작한다").

## 4. 보여 주고 승인받는다

`design/brief.md` 의 절대 경로를 주고 훅·Keep·Out of scope 를 대화창에도 요약한다. 사용자가 고치자고 하면 고치고 다시 보여 준다. 승인하면:

```sh
$GF check evidence
$GF state approve --note "<훅 한 줄>"
```
