# 아트 디렉션

기준 화면: `design/look/frame.png` (추가 장면: 〈파일들〉)
이 문서와 기준 화면이 모든 에셋 생성과 심사의 기준이다. 바꾸려면 사용자 승인을 받는다.

## 한 줄

〈이 게임의 화면을 한 문장으로〉

## 팔레트

- 파일: `design/palette.json` (〈N〉색)
- 바탕 〈#hex〉 · 주조 〈#hex #hex〉 · 강조(상호작용·위험에만) 〈#hex〉
- 색온도 〈차가움/따뜻함〉, 채도 〈낮음/중간/높음〉
- 규칙: 〈예: 플레이어와 위험물만 가장 밝은 색을 쓴다〉

## 선과 형태

- 외곽선: 〈없음 / 1px 어두운 색 / 굵은 검정〉
- 형태 언어: 〈둥글다 / 각지다〉, 비율 〈2등신, 큰 머리 …〉
- 질감: 〈평면 색 / 거친 붓 / 노이즈 없음〉

## 조명

- 주광 방향 〈왼쪽 위〉, 그림자 〈없음 / 바닥 타원 / 길게〉
- 분위기: 〈안개, 림 라이트, 시간대〉

## 카메라와 화면 구성

- 시점 〈측면 / 탑다운 / 3인칭 원거리〉, 화면 〈1280x720〉
- 주인공 크기: 화면 높이의 〈%〉
- 전경/배경 분리: 〈배경은 채도와 대비를 낮춘다〉

## 해상도와 밀도

- 픽셀 스타일: 기준 해상도 〈320x180〉, 캐릭터 〈16x16 / 32x32〉, 색 수 〈16〉, 알파는 0/255 만
- 그 밖: 스프라이트 기준 높이 〈px〉, 텍스처 밀도 〈px/m〉, 삼각형 예산 〈캐릭터 3,000 / 소품 500〉

## UI

- 글꼴 〈〉, 패널 〈생성 텍스처 9-slice / 평면〉, 아이콘 〈선 굵기〉
- 위치와 크기: 〈HUD 는 왼쪽 위, 화면의 10% 안쪽〉

## Do

- 〈지킬 것 3~6개〉

## Don't

- 〈안티 레퍼런스에서 나온 것 3~6개〉
- 특정 작품의 캐릭터·로고·UI 배치를 닮게 하지 않는다
