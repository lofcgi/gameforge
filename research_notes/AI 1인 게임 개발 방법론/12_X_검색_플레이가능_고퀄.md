# X 검색: 플레이 가능한 1인·AI 제작 고퀄 게임 (2026-10-22 ~ 2026-11-22)

조사일 2026-11-22. 사용자의 로그인된 Chrome(Claude in Chrome)에서 X 검색·스레드를 읽기 전용으로 열람했다.

**읽는 법 / 한계 (먼저 읽을 것)**
- 품질 판단은 전부 게시글 본문·참여 수치·답글 반응에 근거한 것이며, **게임을 직접 플레이하지 않았다.** 영상도 재생하지 않았다(스틸 1장만 봄).
- 플레이 링크는 게시글에 적힌 것을 옮겨 적었을 뿐 **직접 열어 로딩을 확인하지 않았다.**
- 수치(좋아요 등)는 2026-11-22 열람 시점 값. 날짜는 X의 `datetime`(UTC) 기준.
- 인용문은 DOM 텍스트 추출 과정에서 `% ? = & ;` 문자가 공백으로 치환됐다. 아래 인용에서 `[%]`, `[?]`는 문맥상 복원한 것이다.
- 중국어·일본어 게시글은 X의 자동 영어 번역 상태로 읽혔다. 해당 인용은 "X 자동번역"으로 표시했고 원문 그대로가 아니다.
- 비용·토큰·시간·판매량은 모두 제작자 자기 보고(self-reported)다.
- 표기: [1차] = 제작자 본인 게시글, [논평] = 제3자 게시글.

## 1. 기간 내 X에 올라온 플레이 가능·1인 설계·AI 제작 게임 중 관찰 품질이 가장 높은 것은 무엇이고 플레이 링크는?

### Takeaway
플레이 링크가 게시글에 명시된 1인 제작물은 13개를 확인했고, 품질 반응과 방법 설명을 함께 보면 Sumiro(@xikhar), Felix Rieseberg의 one-shot FPS, Iron Curtain Call(@whaledevstudios, Steam 데모), 雾锁山门 계열(@op7418), Starry Night Rider(@ebbyamir)가 상위다. 방법 설명이 가장 정교한 @MengTo의 Dark Souls풍 게임과 규모가 가장 큰 @M__Houser의 AOD는 공개 플레이 링크를 찾지 못해 "플레이 불가"로 분리했다.

## 2. 각 제작자가 설명한 방법은 무엇이고, 슬롭을 벗어난 요령으로 무엇을 꼽았나?

### Takeaway
가장 자주 명시된 요령은 "먼저 목표 비주얼(영상·컨셉 페인팅)을 만들고 에이전트가 그것을 쫓게 한다"와 "같은 카메라의 전후 스크린샷을 블라인드 심사 에이전트가 채점하는 루프"다. 조작감은 사람이 매 빌드를 직접 플레이해서 고쳤다는 진술이 반복된다.

### Cited Findings

**Sumiro (@xikhar) — 3D, 24시간** [1차] — [스레드](https://x.com/xikhar/status/2117776295534997818)
- 기획/레퍼런스: "Step 1: Generate a video. Made this with Flux 3 Max on @fal. It's the reference for everything: look, world, character. This project was inspired by Video2Game by @OdinLovis" (영상 1개를 룩·월드·캐릭터 전체의 기준으로 삼음)
- 월드: "Screenshot the video, rebuild assets in Blender, place it in @threejs. Using dynamic workflows in Claude Code, so agents build and check in parallel"
- 캐릭터: "create 4 side views with GPT Image, turn them into a 3D model with @tripoai, let opus add cloth physics and animations"
- 루프: "Step 4: Test the gameplay. Play the prototype and check that it works before building more" → 레벨별 컨셉아트 최대 8장을 GPT Image로 → "Play it, report bugs, let the agents fix them and improve the objects. Repeat."
- 모델 설정: "High effort on Opus 5.5 with ultracode"
- 한계 자인: "the demo video in the post was recorded by claude so it's a bot playing" / "I know music sucks. Claude cannot hear it" / 수익화 의도 없음("This is to experiment with AI gen workflows")
- 요령 평가: 답글 "video reference is such a nice trick"에 "did not expect claude to build the animations and a decent playable game using it in one shot"이라고 답함
- 비용·토큰: 미공개

## 3. 상위 작품에 반복되는 방법은 무엇이고, 3D 고충실도 시도와 2D/스타일라이즈드는 어떻게 다른가? AAA급에 근접한 플레이 가능작이 있는가?
