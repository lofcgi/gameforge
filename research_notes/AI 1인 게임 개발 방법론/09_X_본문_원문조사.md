# X(트위터) 게시물 본문 원문 조사 (2026-10-22 ~ 2026-11-22)

- 조사일: 2026-11-22. 본문은 전부 X 공식 공개 oEmbed(`https://publish.twitter.com/oembed?url=<게시물 URL>&omit_script=1`)로 읽었다.
- 읽는 법
  - **게시일**은 oEmbed가 돌려준 날짜(일 단위)다. 괄호 안 UTC 시각은 status ID(snowflake)에서 역산한 값이다.
  - oEmbed는 긴 게시물을 `…`로 자른다. 잘린 인용은 "(잘림)"으로 표시했고, 잘린 뒷부분은 추정해 채우지 않았다.
  - oEmbed는 좋아요·리포스트·조회수를 주지 않는다. 별도 표기가 없으면 **참여 수치는 미확인**이다.
  - 첨부 이미지·영상(`pic.twitter.com/...`)의 내용은 읽지 못했다. 스레드의 후속 글은 URL을 아는 것만 읽었다.
  - [1차] = 제작자 본인 게시물, [논평] = 제3자 게시물, [홍보] = 도구·서비스 판매 계정의 게시물.

## 1. Slotbound 개발자가 직접 말한 스택·과정·일정·수치

### Takeaway
개발자 계정(@OptimaArchGames)의 X 게시물 3건을 원문으로 읽었고, 기간 내 2건은 **트레일러 공개(10-27)와 48시간 실적(11-15)** 이다. 읽은 X 게시물 어디에도 도구 스택(코딩 에이전트, 엔진, 아트 도구)이나 복제 사건 언급은 없으므로, 스택 충돌은 X 원문으로 해소되지 않는다. 다만 두 스택 설명은 출처 시점이 달라(여름 발언 vs 출시 후 인터뷰) "초기 도구 → 후기 도구"로 양립할 가능성이 있다.

## 5. 접근 경로별 결과

### Takeaway
공식 oEmbed 엔드포인트는 공개 게시물에 대해 잘 작동했다(게시물 57건 시도 중 56건 HTTP 200). 한계는 발견 단계였다. 검색으로는 X 게시물 URL을 거의 찾지 못해, X 링크를 출처로 단 매체에서 URL을 모았다.

### Cited Findings

| 경로 | 결과 | 비고 |
|---|---|---|
| `publish.twitter.com/oembed` (리다이렉트 미추적) | HTTP 301 | `publish.x.com/oembed`로 이동. 리다이렉트를 따라가면 정상 |
| `publish.twitter.com/oembed` → `publish.x.com/oembed` (게시물 URL) | HTTP 200, 56건 | 본문·작성자·날짜 반환. 긴 글은 `…`로 잘림. 참여 수치·이미지 내용 없음 |
| 같은 엔드포인트, `x.com/cdngdev/status/2122488291614412970` | HTTP 404 | 삭제 또는 비공개로 추정 |
| 같은 엔드포인트, X Article URL(`x.com/i/article/2115377047400804352`) | HTTP 404 | X Article 본문은 이 경로로 읽을 수 없음(Nenly 회고) |
| 같은 엔드포인트, 프로필 URL(`x.com/OptimaArchGames`) | HTTP 200 | 타임라인 임베드용 응답이라 게시물 본문은 없음 |
| `t.co` 단축 링크 확인 | HTTP 301 | 목적지 URL만 확인(Steam 페이지, X Article) |
| 웹 검색 `site:x.com ...` (영어·한국어·일본어·중국어 약 10개 질의) | x.com 결과 0건 | 뉴스·블로그만 반환 |
| X 링크를 출처로 단 매체에서 URL 수집 | 성공 | AIGamer 132개 페이지에서 고유 게시물 URL 약 100개, 그중 기간 내 약 65개. Foundplay 2개, PC Gamer 1개 |
| x.com 페이지 직접 열람 | 시도하지 않음 | 이전 라운드에서 HTTP 402. 지시에 따라 제외 |

- 엔드포인트 작동 예시(Grummz 게시물, HTTP 200) — [oEmbed 응답](https://publish.twitter.com/oembed?url=https://x.com/Grummz/status/2122293129504338190&omit_script=1)
- URL 수집의 주 출처 — [AIGamer 사이트맵](https://www.aigamer.gg/sitemap.xml)

### Inferences
- 후속 조사에서 X 본문이 필요하면 "매체 출처 링크에서 status URL 수집 → oEmbed"가 가장 효율적이다. 개발자 계정의 게시물 목록 자체는 허용된 경로로 얻을 수 없다.

### Gaps
- 로그인 없이 특정 계정의 기간 내 게시물 전체를 나열할 방법이 없어, 누락된 게시물이 얼마나 되는지 알 수 없다.
