# 레퍼런스 읽기

고른 것 25장, 피할 예시 4장. 수치는 `traits.json`, 팔레트는 `traits-palette.png`.

## 고른 것들의 공통점

- **화면 구도**: 수면이 화면을 위아래로 나눈다. 위에는 작은 배와 캐릭터, 아래에는 넓은 물속이 단면으로 보인다(100, 114). 낚싯줄이 두 세계를 잇는다.
- **픽셀 밀도**: 캐릭터와 소품이 큼직한 픽셀로 읽힌다(98, 106, 151). 잔무늬보다 덩어리와 실루엣으로 구분된다.
- **색**: 차가운 파랑·청록이 바탕이고(#3368a3, #72b3d3), 나무·흙의 따뜻한 갈색(#875e48, #cbbaa1)과 크림색(#eff4ec)이 사람 사는 곳과 UI를 맡는다. 가장 어두운 색은 순수 검정이 아니라 남보라빛(#1e1c25)이다.
- **깊이에 따른 색 변화**: 얕은 곳은 밝은 청록과 산호(110), 중간은 빛줄기와 유적(109), 심해는 보라·남색에 발광 생물(113). 깊이가 곧 진행도다.
- **따뜻한 빛**: 밤 장면에서는 등불의 주황이 차가운 배경과 대비된다(125, 126). 육지와 항구에 쓴다.
- **캐릭터**: 두 발로 서고 옷을 입은 동물(106, 98, 47). 머리가 크고 몸이 짧다. 표정은 눈과 입 몇 픽셀로 만든다.
- **UI**: 크림색 종이 바탕, 둥근 모서리, 굵은 갈색 테두리(142, 144). 화면의 파랑과 겹치지 않는다.
- **스토리 연출**: 초상화와 대화창(127). 전체 화면 애니메이션 없이 장면을 전달한다.
- **한국풍**: 물결 문양(57), 자개 느낌의 무지갯빛(63), 단청 기둥과 처마(62). 용궁과 UI 장식에만 절제해서 쓴다.

## 피할 것 (안티에서 읽은 것)

- 원색 빨강과 금색이 화면을 덮는 중국풍 궁궐(140). 용궁은 청록·자개색 중심으로 간다.
- 사실적인 비율과 털 질감(42), 3D 실사풍(33).
- 어둡고 거친 분위기(6). 심해도 무섭기보다 신비롭게 간다.

수치로도 같은 방향이다. 고른 쪽이 안티보다 채도가 높고(+0.09) 차갑고(warmth −0.20) 윤곽 밀도가 낮다(−0.09). 즉 더 선명하고, 더 파랗고, 더 단순하다.

## 쏠림 경고에 대해

고른 것 25장 중 20장이 pinterest.com 도메인이라 경고가 뜬다. Pinterest는 모음 사이트이고 각 핀은 서로 다른 작가의 작업이라, 한 작품을 따라가는 상황은 아니다. 특정 한 장의 캐릭터나 구도를 그대로 옮기지 않고, 위의 공통점만 가져간다.

## 아직 비어 있는 것

- 픽셀로 그린 한국 전통 건축·문양 레퍼런스가 약하다. 용궁은 일반 일러스트(57, 62, 63)의 색과 문양을 픽셀로 옮겨야 한다.
- 용왕과 별주부의 픽셀 캐릭터 레퍼런스가 없다. 별주부는 54의 실루엣만 참고한다.
