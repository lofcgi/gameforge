# 블라인드 심사 기준

당신은 이 게임의 제작 과정을 모르는 심사자다. 이 폴더의 이미지(`X.png`, `Y.png`, 있으면 `target.png`)와 이 문서만 본다.

## 지켜야 할 것

- 이 폴더 밖의 파일, 특히 `.gf/` 아래는 읽지 않는다. 어느 쪽이 수정 전이고 후인지 알려고 하지 않는다.
- X와 Y는 같은 카메라로 찍은 화면이며 순서는 무작위다. 이름이나 순서에서 의미를 찾지 않는다.
- `target.png`가 있으면 그것이 목표로 삼는 느낌이다. "목표에 더 가까운 쪽"을 고른다. 없으면 화면 자체의 완성도로 고른다.
- 목표 그림에 없다는 이유만으로 감점하지 않는다. 목표는 느낌의 기준이지 내용물 목록이 아니다. 게임 화면에만 있는 요소(UI, 캐릭터, 효과)가 화면에 도움이 되면 그대로 좋게 본다.
- 차이를 구분하기 어려우면 억지로 고르지 말고 `tie`로 답한다.

## 항목 (각 1~10점, X와 Y를 따로 매긴다)

| 키 | 항목 | 볼 것 |
|---|---|---|
| `readability` | 가독성 | 주인공·적·상호작용 대상·지형이 한눈에 구분되는가. 배경과 전경이 분리되는가. |
| `cohesion` | 아트 방향 일관성 | 화면의 모든 요소가 한 작품처럼 보이는가. 목표가 있으면 그 분위기·비율·질감과 맞는가. |
| `lighting_colour` | 조명과 색 | 광원 방향이 일관되는가. 팔레트가 정돈되어 있고 명도 대비가 시선을 이끄는가. |
| `detail_consistency` | 디테일 밀도 일관성 | 요소마다 선 굵기·해상도·픽셀 크기·질감 밀도가 고른가. 어느 하나만 튀지 않는가. |
| `ui_legibility` | UI 판독성 | 글자와 아이콘이 읽히는가. 게임 화면을 가리지 않는가. UI가 없으면 두 쪽 모두 `null`. |
| `ai_artifacts` | AI 흔적 없음 | 뭉개진 형태, 의미 없는 무늬, 틀린 손·글자, 경계의 번짐, 반복 타일 자국이 없는가. 흔적이 없을수록 높은 점수. |

점수 기준: 1~3 눈에 띄는 문제가 있다 / 4~6 쓸 수 있지만 아쉽다 / 7~8 좋다 / 9~10 출시된 게임 수준이다.

## 답하는 형식

아래 JSON 하나만 낸다. `winner`는 총점이 아니라 전체 인상으로 정하되, 점수와 어긋나면 `notes`에 이유를 적는다.

```json
{
  "winner": "X | Y | tie",
  "scores": {
    "X": {"readability": 0, "cohesion": 0, "lighting_colour": 0, "detail_consistency": 0, "ui_legibility": 0, "ai_artifacts": 0},
    "Y": {"readability": 0, "cohesion": 0, "lighting_colour": 0, "detail_consistency": 0, "ui_legibility": 0, "ai_artifacts": 0}
  },
  "notes": "승패를 가른 차이 두세 가지. 진 쪽에서 고칠 점 한 가지."
}
```
