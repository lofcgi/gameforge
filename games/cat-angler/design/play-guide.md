# 플레이 안내

장소마다 화면이 나뉜 판이다: 타이틀 → 여는 컷신 → 항구 마을 ⇄ 채집지, 가게 네 곳의 실내, 부두 → 바다 ⇄ 섬 → 닫는 컷신. 그림과 소리는 `assets/game/` 에 들어온 만큼 쓰이고, 아직 없는 것은 도형으로 그린 임시 그림과 무음으로 대신한다(F3 으로 빠진 목록을 본다).

## 실행

```sh
gf() { uv run -q --project /Users/iyeonsang/Desktop/game/harness/tools gf --project /Users/iyeonsang/Desktop/game/games/cat-angler "$@"; }
gf engine run                               # 창이 뜬다. 닫으면 끝
gf engine run --record --id play1           # 입력과 상태를 captures/sessions/play1.jsonl 에 남긴다
gf engine replay play1 --shot-every 1       # 기록 재생: 반응 없는 입력 후보와 스크린샷
godot --path /Users/iyeonsang/Desktop/game/games/cat-angler      # 하네스 없이
```

## 저장

- 마을에 들어설 때마다 저절로 저장하고, 메뉴(P)의 "저장하기"로 직접 저장한다. 타이틀의 "이어하기"로 이어 간다.
- 저장되는 것: 돈, 낚싯대와 배의 단계, 내구도, 미끼, 재료, 어창, 도감, 길잡이 진행, 있던 화면과 자리. 파일은 `user://save.json`(macOS: `~/Library/Application Support/Godot/app_userdata/고양이 낚시꾼/`).
- 환경 변수 `CA_SAVE`: `off` 면 읽지도 쓰지도 않는다. 다른 값이면 그 이름의 칸(`user://<이름>.json`)을 쓴다.
- 자동 실행(봇, 캡처, 재생, 테스트)에서는 기본이 `off` 다. 남은 저장 파일이 실행마다 타이틀 메뉴를 바꾸면 재생이 어긋나기 때문이다.
- **재생할 기록을 남길 때는 `CA_SAVE=off gf engine run --record ...` 로 시작한다.** 저장이 있는 채로 기록하면 재생(저장 없음)과 타이틀 메뉴의 처음 커서가 달라진다.

## 조작 (키보드. 마우스 왼쪽 버튼은 Space 와 같다)

화면 아래 줄에 지금 쓸 수 있는 키만 나온다. 메뉴(P)의 "조작 안내"에 전체 표가 있다.

| 키 | 걷는 화면(마을·채집지·섬) | 가게 안 | 운항 | 낚시(닻 내림) | 줄다리기 |
|---|---|---|---|---|---|
| ← → (A D) | 걷기. 마을 왼쪽 끝 → 채집지, 채집지 오른쪽 끝 → 마을 | 고르기 | 배 몰기 | (닻을 올리라는 안내) | 물고기를 따라 배를 옮긴다 |
| ↑ ↓ (W S) | ↑ 문 앞에서 들어가기 | 고르기 | | 줄 올리기·내리기 | |
| Space (Z) | 문 들어가기, 줍기, 배 타기 | 대사 넘기기, 만들기·팔기·맡기기·사기 | 닻 내리기. 부두 앞: 항구에 대기, 섬 기슭: 섬에 대기 | 미끼 흔들기(주변 물고기를 부른다) | 누르는 동안 감기, 떼면 풀기 |
| X (Esc) | 메뉴 | 대사 건너뛰기, 나가기 | 메뉴 | 닻 올리기 | 줄 끊기(미끼만 잃는다) |
| Q | 미끼 바꾸기 | | 미끼 바꾸기 | 미끼 바꾸기 | |
| H | 어창 | | 어창(놓아주기) | 어창 | |
| C (Tab) | 도감 | 도감 | 도감 | 도감 | |
| P (Enter) | 메뉴(계속·저장·길잡이 끄기·조작 안내·타이틀로) | 메뉴 | 메뉴 | 메뉴 | 메뉴 |
| F3 | 빠진 그림·소리 목록 | | | | |

컷신은 X 를 1초쯤 누르고 있으면 건너뛴다(화면 아래 안내에 "길게 눌러 건너뛰기"로 나온다. 누르는 동안 오른쪽 위 막대가 찬다).

바다 화면은 세계를 2배로 당겨 보여 준다. 화면 가로가 80m, 세로가 약 22m 다.

## 처음 2분 (길잡이)

화면 위의 "할 일" 띠와 화살표가 첫 출항을 이끈다. 메뉴에서 끌 수 있다.

1. 마을 왼쪽 끝으로 나가 채집지에서 약초·곤충·열매를 줍는다(반짝이는 자리, 종류마다 4곳. 귀항하면 다시 자란다).
2. 미끼 공방(마을 맨 왼쪽 집)에서 좌우로 미끼를 고르고 Space 로 만든다. 풀떡밥 4개를 들고 시작한다.
3. 마을 오른쪽 끝 부두에서 Space 로 배를 탄다.
4. 오른쪽으로 나가 새가 도는 어군을 찾아 Space 로 닻을 내린다. 길잡이는 가진 미끼로 낚을 수 있는 어군을 먼저 가리킨다. 길잡이가 끝난 뒤에도 220m 안의 어군이 화면 밖에 있으면 가장자리에 "어군 152m →"처럼 쪽과 거리가 뜬다. 떠다니는 상자와 병은 닿으면 건진다.
5. ↓ 로 미끼를 물고기 깊이에 맞춘다. 할 일 띠가 깊이를 알려 주고("↓ 로 미끼를 2~10m 까지 내리자 (멸치)"), 왼쪽 대나무 자에 지금 미끼가 무는 깊이가 초록 띠로 나온다. 맞는 미끼면 다가와 건드리다 문다. 안 맞으면 `?` 를 띄우고 돌아서며 "전갱이: 벌레 미끼만 문다. Q 로 미끼를 바꾸자"가 뜬다. 미끼가 떨어지거나 이 자리에 무는 고기가 없으면 할 일 띠가 그렇게 말한다.
6. 물면 줄다리기다. 오른쪽 세로 게이지가 장력이다. "버틴다! 풀어라"에는 Space 를 떼고 "지쳤다! 감아라"에는 누른다. 위 칸에 닿으면 끊어지고 아래 칸에 오래 있으면 바늘이 빠진다. 옆으로 달아나는 큰 물고기는 ← → 로 따라간다.
7. 어창이 차거나 배가 위험하면 X 로 닻을 올리고 왼쪽 끝 부두 앞에서 Space.
8. 어시장에서 판다(하나씩, 또는 "모두 팔기"). 조선소에서 수리·개조, 낚시 가게에서 낚싯대.

진행: 낚싯대 2단계(100닢) → 배 2단계(180닢)로 먼바다 → 작은 섬(1440m, 왼쪽 기슭에 배를 댄다)에서 섬꽃 → 낚싯대 3단계(420닢), 배 3단계(650닢) → 미끼 공방에서 용궁 미끼(약초+곤충+열매+섬꽃) → 심해 입구의 소용돌이 자리(2250m) 바닥 근처 132~147m 의 검은 그림자 → 낚아서 부두에 대면 닫는 컷신.

배 등급보다 거친 구간에서는 큰 파도를 맞을 때마다 내구도가 깎인다. 0 이 되면 항구로 떠밀려 오고 어창의 절반을 잃는다.

낚시 중에 닻을 내린 어군 위의 새는 자리를 비킨다(고양이 머리와 겹쳐서).

거리 눈금: 부두 306m, 얕은 바다 ~900m, 먼바다 ~1800m, 심해 입구 ~2400m. 암초 1200m, 작은 섬 1440m, 난파선 1640m, 소용돌이 자리 2250m. 세계 1px 은 가로 0.25m, 세로 0.125m 이고 바다 화면은 그것을 2배로 그린다(화면 너비 = 80m).

## 디버그 시작

`gf engine` 명령은 게임에 인자를 넘기지 못하므로 환경 변수 `CA_START` 를 쓴다. Godot 을 직접 띄울 때는 `-- --start=...` 도 된다. 값은 `키=값` 을 쉼표로 잇는다. 주면 타이틀과 여는 컷신을 건너뛴다.

| 키 | 뜻 | 예 |
|---|---|---|
| `scene` | 시작할 화면: `town`(기본), `forage`, `island`, `in_bait`, `in_market`, `in_yard`, `in_tackle` | `scene=in_market` |
| `x` | 이 거리(m)의 바다 위에서 시작 | `x=1010` |
| `coins` | 가진 돈 | `coins=500` |
| `rod`, `boat` | 장비 단계 1~3 | `rod=2,boat=2` |
| `baits` | 미끼 네 종류를 이만큼씩 | `baits=8` |
| `legendbait` | 용궁 미끼만 따로 | `legendbait=1` |
| `mats` | 재료 네 종류를 이만큼씩 | `mats=3` |
| `bait` | 처음 고른 미끼(herb/bug/berry/legend) | `bait=berry` |
| `hold`, `caught` | 어창에 실린 물고기, 도감에 기록된 어종(`+` 로 잇는다) | `hold=legend`, `caught=anchovy+scad` |
| `dur` | 배 내구도 | `dur=8` |
| `guide` | `0` 이면 길잡이를 끈다 | `guide=0` |
| `intro` | `1` 이면 여는 컷신부터 | `intro=1` |

그 밖의 환경 변수: `CA_DEBUG=1`(빠진 에셋 목록을 켠 채 시작. 브리지 상태에 `missing_assets` 가 실린다), `CA_PROFILE=1`(틱에 든 시간을 5초마다 출력).

```sh
CA_START="coins=300,rod=2,boat=2,baits=6,x=1010" gf engine run             # 먼바다부터
CA_START="rod=3,boat=3,baits=8,legendbait=2,x=2200" gf engine run          # 전설의 심해어 앞에서
CA_START="scene=in_yard,coins=700,dur=10" gf engine run                    # 조선소
godot --path . -- --start=coins=999,rod=3,boat=3                           # 하네스 없이
```

같은 기록을 재생할 때도 같은 `CA_START` 를 줘야 한다.

## 화면마다 스크린샷 찍기

`bot/shot_*.json` 은 화면 하나를 여는 짧은 입력이다.

```sh
zsh bot/capture_all.sh                      # 아래 전부와 바다 바닥·암초·난파선까지 한 번에 다시 찍는다
gf engine capture --out captures/screens/title --at 1
gf engine capture --out captures/screens/start --script bot/shot_start.json --at 0.62,2.5,5.2,8.5        # 전환, 컷신, 마을, 채집지
CA_START="scene=in_bait,mats=3,guide=0" gf engine capture --out captures/screens/in_bait --script bot/shot_shop.json --at 0.9,1.9
CA_START="x=520,baits=5,guide=0" gf engine capture --out captures/screens/fish --script bot/shot_fish.json --at 2.5,6
CA_START="scene=town,caught=anchovy+scad" gf engine capture --out captures/screens/codex --script bot/shot_codex.json --at 1.5
```

## 플레이하면서 볼 것

| 판정 | 해 볼 것 |
|---|---|
| 배를 모는 느낌, 무게 | 최고 속도에서 손을 떼고 미끄러지는 거리, 반대로 꺾기, 먼바다(`x=1010`)와 심해 입구(`x=2000,boat=3`)에서 파도를 탈 때 기울고 떠오르는 것. 카메라가 가는 쪽을 앞서 보여 주는 것이 편한가 |
| 이동이 지루하지 않은가 | 부두에서 심해 입구 끝까지 한 번에 가 본다. 빈 화면이 이어지는 곳이 있는가. 마을을 걷는 거리가 길지 않은가(부두 ↔ 어시장 약 7초) |
| "조금만 더"와 "돌아가야 하나" | 나룻배로 먼바다 가장자리(900~1000m)에 나가 본다. 내구도 막대가 판단에 쓰이는가 |
| 깊이 조준 | 넙치(바닥 23~30m)와 멸치(2~10m)를 번갈아 노려 본다. 왼쪽 깊이 눈금이 읽히는가 |
| 줄다리기 | 넙치, 방어, 곰치, 전설 순으로. "곧 버틴다" 예고(0.38초)가 반응하기에 충분한가. 왜 졌는지 알 수 있는가 |
| 가게 화면 | 미끼 공방에서 재료가 작업대로 가 미끼가 되는 것이 읽히는가. 어시장에서 하나씩 팔 때와 모두 팔 때. 조선소의 다음 배 설계도, 낚시 가게의 견주기 판 |
| 처음 2분 | 길잡이만 보고 첫 물고기를 팔 때까지 막히는 곳이 없는가 |
| 전설 어종이 정점인가 | `CA_START="rod=3,boat=3,baits=8,legendbait=2,x=2200"` |

## 알려진 거친 부분

- 낚을 때마다 줄이 수면으로 돌아와 깊은 곳에서는 다시 내리는 데 몇 초가 든다.
- 닻을 내린 뒤에는 배를 옮길 수 없다. 물고기가 멀면 닻을 올리고 다시 자리를 잡는다.
- 큰 파도는 피할 수 없고 배 등급으로만 버틴다.
- 미끼가 남아돈다(채집 한 번에 재료 12개). 미끼는 "어떤 어종이 무는가"만 정하고 수량의 압박은 거의 없다.
- 전설의 심해어는 한 마리다. 싣고 오다 난파해 잃으면 소용돌이 자리에 다시 나온다.
- 바다만 2배로 당겨 그린다. 마을·실내는 1배라 화면을 오갈 때 고양이 크기가 달라지고, 바다의 HUD 글자는 세계보다 픽셀이 잘다.
- 화면 가로가 80m 라 큰 어선의 최고 속도에서는 앞이 1초 남짓만 보인다.
- 얕은 바다에서 먼바다로 내려가는 비탈은 무늬 없는 모래 면이다.
- 저장은 한 칸이다. 바다 위에서 저장하고 이어 하면 어군과 떠다니는 물건은 새로 놓인다.
