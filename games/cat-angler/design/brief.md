# 설계 브리프: 고양이 낚시꾼 (가제)

별주부전을 모티브로 한 2D 픽셀 낚시 성장 게임. 배를 몰고 옆으로 길게 이어진 바다를 점점 멀리 나가며 낚는다. 20분 분량의 첫 데모를 만든다.

## 한 문장

용왕의 병을 고칠 전설의 심해어를 낚으려고, 사냥 본능밖에 없는 고양이가 육지 미끼를 싣고 작은 나룻배로 점점 더 멀고 깊은 바다로 나간다.

## 이야기 (데모 범위)

- **여는 장면**: 용왕이 병들고, 영약은 전설의 심해어뿐이다. 이 물고기는 육지의 재료로 만든 미끼에만 입질한다. 별주부가 사냥꾼을 찾아 육지로 올라와 고양이를 만난다.
- **고양이의 동기**: 충성도 영웅심도 없다. "세상 모든 물고기를 낚아 보겠다"는 욕심으로 거래를 받는다. 용왕은 전설 어종마다 보물과 장비를 주기로 한다.
- **닫는 장면**: 첫 전설의 심해어를 낚아 용궁에 바친다. 용왕이 조금 나아지고, 더 먼 바다에 다음 전설이 있다는 말로 끝난다.
- 원전과 달리 고양이는 속지도 도망치지도 않는다. 거래가 서로에게 이득이라서 계속한다.
- 별주부는 이야기 장면에만 나온다.

## 세계의 모양

하나로 이어진 긴 바다다. 왼쪽 끝이 항구이고 오른쪽으로 갈수록 멀고 깊다. 화면은 배를 따라 좌우로 스크롤되고, 낚싯줄을 내리면 미끼를 따라 아래로 내려간다.

```
거리     0m          300m              900m               1800m          2400m
       ├─ 육지·항구 ─┼──── 얕은 바다 ────┼───── 먼바다 ──────┼── 심해 입구 ──┤
수면    채집지 부두    잔잔함             파도 중간            파도 거셈
        상점 조선소    어군  떠다니는 상자   암초 섬  난파선      소용돌이 자리
       ─────────────────────────────────────────────────────────────────────
바닥    (육지)        모래 30m           유적 80m            해구 150m
                                                            ★ 전설의 심해어
```

- **구간은 벽이 아니라 파도로 나뉜다.** 멀리 갈수록 파도가 거세지고, 배가 약하면 내구도가 깎인다. 내구도가 바닥나면 항구로 떠밀려 돌아오고 어창의 절반을 잃는다.
- **깊이는 바닥이 정한다.** 같은 자리에서 낚싯대가 닿는 만큼만 내려간다. 먼바다에 가도 낚싯대가 짧으면 위쪽 물고기만 낚는다.
- 구간이 바뀌면 하늘, 수면 문양의 색, 물색, 배경(먼 섬, 구름)이 서서히 바뀐다.

## 핵심 반복 (한 번의 출항 2~4분)

```
항구 ─ 채집지에서 재료 줍기 → 미끼 만들기 → 배 수리·업그레이드
  │
출항 ─ 배를 몰아 나간다 → 어군·섬·떠다니는 물건을 보고 자리를 고른다
  │      → 닻을 내린다 → 깊이를 맞춰 미끼를 내린다 → 입질 → 줄다리기 → 어창에 담는다
  │      → 자리를 옮기거나 더 멀리 간다 (파도가 내구도를 깎는다)
  │
귀항 ─ 어창이 찼거나 내구도가 위험하면 돌아온다 → 팔기 → 업그레이드 → 도감 확인
```

출항마다 판단이 있다: 가까운 곳에서 안전하게 채울 것인가, 내구도를 걸고 멀리 나가 비싼 물고기를 실을 것인가.

## 항해

- **조작**: 좌우로 배를 몬다. 가속과 감속에 무게가 있고, 멈추면 조금 미끄러진다. 닻을 내리면 그 자리에 멈춰 낚시 상태가 된다.
- **파도**: 수면이 실제로 일렁이고 배가 그 위에서 기울고 오르내린다. 구간이 멀수록 파고가 크다. 배의 등급보다 거친 파도에서는 큰 파도를 맞을 때마다 내구도가 깎인다.
- **어창**: 물고기는 크기만큼 칸을 차지한다. 가득 차면 더 낚을 수 없고, 싼 물고기를 놓아주고 비싼 것을 실을 수 있다.

## 바다에서 만나는 것

| 요소 | 내용 | 역할 |
|---|---|---|
| 어군 표시 | 수면의 잔물결과 물거품, 그 위를 도는 새 떼. 종류에 따라 모양이 다르다 | 어디에 닻을 내릴지 고르게 한다. 시간이 지나면 사라지고 다른 곳에 생긴다 |
| 암초 | 먼바다의 얕은 바위 지대. 여기에만 사는 어종이 있다 | 덜 찾는 장소 1 |
| 작은 섬 | 먼바다 중간의 무인도. 배를 대고 내려서 육지에 없는 재료를 줍는다 | 덜 찾는 장소 2. 전설용 미끼의 마지막 재료가 여기 있다 |
| 난파선 | 먼바다 바닥의 가라앉은 배. 주변에 큰 물고기가 숨는다 | 덜 찾는 장소 3 |
| 떠다니는 물건 | 표류하는 상자와 병. 다가가 건지면 돈, 재료, 병 속 쪽지(바다 이야기 조각)가 나온다 | 항해 중 손이 심심하지 않게 한다 |

## 낚시 조작

- **깊이 조준**: 줄을 내리고 올려 물고기 앞에 미끼를 놓는다. 카메라가 미끼를 따라 내려가고 화면 가장자리에 깊이 눈금이 보인다. 물고기마다 사는 깊이와 좋아하는 미끼가 다르다.
- **줄다리기**: 입질하면 장력 게이지가 나온다. 물고기가 버틸 때는 풀고, 지칠 때 당긴다. 장력이 한계를 넘으면 줄이 끊어지고, 너무 느슨하면 바늘이 빠진다. 큰 물고기는 좌우로 달아나며 배를 끌고 간다.
- **난이도**: 작은 물고기는 거의 실패 없이 올라온다. 큰 물고기와 전설 어종만 길고 어렵다. 놓쳐도 잃는 것은 미끼 하나다.
- 모든 입력에는 즉시 반응이 있어야 한다. 반응 없는 입력은 버그로 다룬다.

## 화면 구성

한 화면에 몰아넣지 않는다. 장소마다 화면이 따로 있고, 문이나 화면 끝으로 가면 전환 연출(페이드, 조리개)과 함께 넘어간다.

```
타이틀 → 여는 컷신 → 항구 마을(바깥) ⇄ 채집지
                        │  ├ 미끼 공방(실내)
                        │  ├ 어시장(실내)
                        │  ├ 조선소(실내·선거)
                        │  └ 낚시 가게(실내)
                        └ 부두 → 바다(항해 ⇄ 낚시) ⇄ 섬(상륙)
                                   └ 전설을 바치면 → 닫는 컷신
```

| 화면 | 내용 |
|---|---|
| 타이틀 | 로고와 움직이는 바다 배경 |
| 여는 컷신 | 용왕의 병 → 별주부가 육지로 → 고양이와의 거래. 장면마다 그린 그림이 움직인다 |
| 항구 마을 | 옆으로 걸어 다니는 바깥 풍경. 건물마다 문이 있고 들어가면 실내 화면으로 바뀐다. 오른쪽 끝이 부두 |
| 미끼 공방 | 작업대 화면. 가진 재료를 올려 미끼를 만든다. 재료와 결과물이 그림으로 보이고 만드는 동작이 있다 |
| 어시장 | 주인 캐릭터가 있는 판매 화면. 어창의 물고기를 하나씩 올려 값을 받는다 |
| 조선소 | 선거에 내 배가 보이고, 다음 단계의 배를 미리 본 뒤 개조한다. 수리도 여기서 |
| 낚시 가게 | 벽에 낚싯대가 걸려 있고 주인이 설명한다 |
| 채집지 | 숲 가장자리와 들판. 약초·곤충·열매가 자라고 걸어 다니며 줍는다 |
| 바다 | 이어진 긴 바다. 항해와 낚시 |
| 섬 | 배를 대면 넘어가는 작은 섬 화면. 희귀 재료를 줍는다 |
| 도감 | 책 모양의 전체 화면. 어종마다 그림과 설명 |
| 닫는 컷신 | 용궁에 전설의 심해어를 바치는 장면 |

가게 주인들은 각자 다른 동물 캐릭터이고 초상화와 대사가 있다. 실내 화면은 각각 따로 그린 배경이다.

## 데모 분량

| 항목 | 수량 | 내용 |
|---|---|---|
| 바다 구간 | 3 | 얕은 바다(바닥 30m), 먼바다(80m), 심해 입구(150m). 전체 길이 약 2,400m |
| 덜 찾는 장소 | 3 | 암초, 작은 섬, 난파선 |
| 일반 어종 | 12 | 구간마다 3종 + 암초·난파선 전용 3종 |
| 전설 어종 | 1 | 심해 입구의 전설의 심해어. 데모의 마지막 싸움 |
| 재료 | 4 | 육지의 약초·곤충·열매 + 섬의 희귀 재료 |
| 미끼 | 4 | 기본 3종 + 네 재료를 합친 전설용 1종 |
| 낚싯대 | 3단계 | 닿는 깊이 30m → 80m → 150m, 버티는 힘 증가 |
| 배 | 3단계 | 버티는 파도 잔잔함 → 중간 → 거셈, 내구도와 속도 증가, 어창 6 → 10 → 14칸. 겉모습이 달라진다 |
| 이야기 컷 | 여는 장면 6~8컷, 닫는 장면 2컷 | 전체 화면 픽셀 그림 + 자막 + 가벼운 움직임 |

**플레이 시간**: 제한을 두지 않는다. 내용이 충분히 재미있을 때까지 넓힌다. 참고 배분은 여는 장면 2분, 출항 여러 번, 닫는 장면 1분.

**진행의 흐름**: 나룻배로 얕은 바다 → 돈을 모아 낚싯대 2단계 → 배 2단계로 먼바다 진입 → 섬에서 희귀 재료 → 낚싯대 3단계와 배 3단계 → 심해 입구에서 전설용 미끼로 전설의 심해어.

## 성장

네 축이 서로 다른 것을 연다. 하나만 올려서는 다음으로 못 간다.

- **배**: 얼마나 멀리 가서 얼마나 싣고 오는가.
- **낚싯대**: 얼마나 깊이 내리고 얼마나 큰 물고기를 버티는가.
- **미끼**: 어떤 어종이 입질하는가.
- **도감**: 낚은 어종의 기록. 아직 못 낚은 어종의 구간·깊이·미끼 힌트를 실루엣과 함께 준다.

돈은 물고기를 팔아 번다. 전설 어종은 팔지 않고 용궁에 바치며, 그 보상으로 다음이 열린다.

## 유지할 것 (Keep)

- 옆에서 본 단면. 수면 위는 항해, 수면 아래는 낚시
- 큼직한 픽셀, 덩어리와 실루엣 위주의 귀여운 형태
- 멀리, 깊이 갈수록 바뀌는 색(밝은 청록 → 파랑과 유적 → 남보라와 발광 생물)
- 부드러운 움직임: 일렁이는 수면, 배의 기울어짐, 줄의 휘어짐, 물고기의 헤엄, 고양이의 꼬리와 귀
- 한국풍은 수면 문양, 용궁, UI 장식에만 절제해서

## 피할 것 (Avoid)

- 원색 빨강·금색이 덮는 궁궐, 사실적인 비율, 어둡고 거친 분위기
- 시간 제한에 쫓기는 느낌. 위험은 스스로 고른 만큼만
- 낚시와 무관한 긴 육지 탐험
- 빈 바다를 오래 이동만 하는 구간. 화면 두 개 너비 안에 항상 볼거리가 있어야 한다
- 특정 기존 게임의 캐릭터·화면·UI를 닮게 만드는 것

## 범위 밖 (Out of scope, 데모 이후)

- 낮과 밤, 날씨 변화, 계절
- 여러 구역의 육지 탐험, 마을 사람들과의 관계
- 별주부의 동행
- 네 번째 이후의 구간, 두 번째 이후의 전설 어종
- 배 위의 선원, 그물이나 통발 같은 다른 어법
- 위에서 내려다본 해도 화면

## 사람이 판정할 것

- 배를 모는 느낌이 좋은가. 파도 위에서 무게가 느껴지는가
- 이동이 지루하지 않은가. 볼거리와 건질 것이 충분한가
- "조금만 더 나가 볼까"와 "이제 돌아가야 하나"의 갈등이 생기는가
- 줄다리기가 손에 붙는가. 깊이를 맞추는 조작이 답답하지 않은가
- 한 번의 출항이 지루해지기 전에 다음 업그레이드가 오는가
- 전설 어종과의 싸움이 데모의 정점으로 느껴지는가
- 귀여운가. 고양이와 물고기에 정이 가는가
- 소리가 어울리는가

## 인수 기준

- 처음부터 끝까지 막히는 곳 없이 깰 수 있다
- 봇이 정해진 입력으로 여는 장면부터 닫는 장면까지 도달한다
- 항해와 낚시의 모든 입력에 0.1초 안에 눈에 보이는 반응이 있다
- 어종 13종, 미끼 4종, 낚싯대 3단계, 배 3단계, 덜 찾는 장소 3곳이 게임 안에서 모두 쓰인다
- 바다의 어느 지점에서도 화면 두 개 너비 안에 어군·장소·떠다니는 물건 중 하나가 있다
- 화면의 모든 그림이 같은 팔레트와 픽셀 밀도를 쓴다
- 효과음과 음악이 실행 중에 실제로 나고, 음악의 반복 지점에 끊김이 없다
