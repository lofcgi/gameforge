# 에셋 상태 (2026-11-23 그림·소리 제작, 같은 날 다듬기)

`design/asset-spec.md` 의 항목별 상태다. 완료 = 규격 경로에 있고 팔레트 24색·반투명 없음 검사를 통과했다. 약함 = 쓸 수는 있으나 눈에 띄는 흠이 있다. 소리는 측정만 했고 아무도 듣지 않았다.

## 확인한 것과 못 한 것

- `assets/game/` 의 PNG 232장 전부 팔레트 24색 안이고 반투명 픽셀이 없다(`gf check assets` 가 다듬기 뒤의 파일로 통과). 게임은 그리는 동안 빛줄기·구간 섞임·물에 잠긴 선체에 알파를 써서 화면에는 팔레트 밖의 중간색이 생긴다.
- `gf check assets`, `gf check audio --require` 는 통과한다(2026-11-23). 검사기가 `assets/game/` 를 뺀 경로(`boats/boat1.png`, `Galmuri11.ttf`)를 `assets/game` 아래에서 찾게 고쳤고, 소리는 `scripts/audio.gd` 의 `TRACKS` 에 파일 경로를 적어 37개 모두 읽힌다. `"fish/%s_card.png" % id` 처럼 조합하는 경로와 확장자 없는 애니메이션 이름은 검사기가 읽지 못한다. 그쪽은 실행 중의 빠진 에셋 목록(`missing_count`)으로 본다.
- 실행 중 소리(`gf engine audio`, 엔진 안의 신호. 스피커 소리가 아니다): 음악만 나는 구간 −26 dB 안팎, 알림·보상 효과음의 구간 음량은 그보다 4~6 dB, 피크는 7~10 dB 크다. 전체 피크 −3.5 dB(고치기 전 +1.7 dB 로 넘쳤다). `legend_fight` 와 닫는 컷신은 실행 중에 재지 못했다.
