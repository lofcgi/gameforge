# 아트 디렉션

기준 화면: `design/look/target.png`. 모든 에셋과 화면은 이 그림과 나란히 놓았을 때 같은 게임으로 보여야 한다. 블라인드 심사의 목표도 이 그림이다.

팔레트: `design/look/palette.json` (24색). 게임용 에셋은 전부 이 팔레트로 양자화한다.

## 화면 구성

- 기준 해상도 320×180, 정수배 확대. 옆에서 본 단면. 기준 화면은 분위기와 화풍의 목표이고, 실제 게임은 한 화면에 다 담지 않고 스크롤한다.
- **항해 중**: 카메라가 배를 따라 좌우로 움직인다. 수면선은 화면 가운데보다 조금 아래(위에서 약 55%). 위는 하늘과 먼 배경(구름, 섬, 산), 아래는 수면 바로 밑의 얕은 물속이 보여 어군의 그림자가 비친다.
- **낚시 중**: 닻을 내리면 카메라가 미끼를 따라 아래로 내려간다. 배는 화면 위로 밀려 나가고 화면 대부분이 물속이 된다. 화면 가장자리에 깊이 눈금.
- 배경은 3겹으로 다른 속도로 움직인다(먼 산과 구름, 중간의 섬, 가까운 파도).
- 배와 고양이는 화면 가로 가운데 부근. 낚싯줄은 낚싯대 끝에서 내려가며 물고기가 당기면 휜다.
- 자개빛 바닥과 옥색 누각은 심해 입구 구간의 바닥에만 나온다.

## 픽셀

- 고양이: 약 24×28px. 머리가 몸보다 크다. 눈은 2×2px 점, 입은 3~4px.
- 배: 1단계 약 56×16px. 단계가 오를수록 길어지고 구조물이 붙는다.
- 물고기: 작은 것 12×8px, 중간 20×12px, 큰 것 32×20px, 전설 어종 64×32px 이상.
- 외곽선은 1px, 순수 검정이 아니라 팔레트의 가장 어두운 색(#17121B)이나 그 물체의 어두운 색.
- 안티에일리어싱, 반투명 가장자리, 그라데이션 금지. 색 전환은 디더링이나 물결 모양 경계로 한다.

## 색 규칙

| 영역 | 색 | 팔레트 |
|---|---|---|
| 하늘 | 옅은 민트 | #B8D0BF, #BAEADC, #E9F3E2 |
| 수면의 물결 문양 | 청록 + 크림 테두리 | #28706F, #439083, #54A9A7, #E5DDC8 |
| 얕은 바다 (0~30m) | 밝은 청록 | #76D7D9, #5DC5CB, #54A9A7 |
| 중간 바다 (30~80m) | 파랑 + 빛줄기 | #468DB4, #426A96, #7BAEB9 |
| 심해 입구 (80~150m) | 남보라 | #2E3068, #1B2139, #17121B |
| 나무(배, 낚싯대, 부두) | 따뜻한 갈색 | #5E342B, #8C533C, #B4774F |
| 고양이 털 | 주황 + 크림 | #D79966, #DFB68B, #E5DDC8 |
| UI 바탕 | 크림색 종이 | #E5DDC8, #E9F3E2, 테두리 #8C533C |

- 깊이가 곧 진행도다. 해역이 바뀌면 물색이 위 표의 다음 단계로 넘어간다.
- 따뜻한 색(갈색, 주황, 크림)은 고양이·배·육지·UI에만 쓴다. 물속은 차가운 색이다. 그래서 주인공이 항상 눈에 띈다.
- 심해의 발광 생물과 미끼에만 밝은 하늘색(#76D7D9)과 주황(#D79966)을 점으로 쓴다.
- 원색 빨강과 금색은 쓰지 않는다.

## 물고기

- 얕은 바다: 연두·옥색 계열의 둥글고 순한 형태.
- 중간 바다: 회보라·청회색, 조금 크고 무늬가 있다.
- 심해: 어두운 몸에 발광점. 형태가 낯설다(긴 몸, 큰 입, 촉수).
- 전설 어종: 평소에는 몸 전체가 어두운 실루엣으로만 보인다. 입질한 뒤에야 색이 드러난다.
- 모든 물고기는 큰 눈 하나와 단순한 지느러미. 무섭지 않고 신비롭게.

## 한국풍 요소 (절제해서)

- 수면선의 전통 물결 문양: 모든 해역에 공통. 이 게임의 얼굴이다.
- 자개빛 바닥: 심해 입구에서만.
- 옥색 기와지붕의 누각: 용궁과 심해 입구 배경에만.
- UI 장식: 창 모서리에 물결 문양 한 조각.

## 움직임

부드러움은 프레임 수가 아니라 계속 움직이는 작은 것들로 만든다.

- 배: 1~2px 위아래로 천천히 흔들린다. 고양이도 함께 움직인다.
- 고양이: 꼬리가 느리게 흔들리고, 가끔 귀가 움찔한다. 입질하면 귀가 선다.
- 낚싯줄: 물고기가 당기면 휘고 떨린다. 장력이 높으면 색이 밝아진다.
- 물고기: 몸통이 2~4프레임으로 헤엄친다. 방향을 틀 때 한 프레임 눌린다.
- 물: 수면 문양이 좌우로 천천히 흐르고, 빛줄기가 느리게 일렁인다.
- 화면: 큰 물고기를 올릴 때 짧게 흔들리고 멈춘다(히트스톱 4~6프레임).

## UI

- 크림색 종이 바탕에 갈색 1px 테두리, 모서리는 2px 둥글림.
- 글자는 픽셀 글꼴, 어두운 갈색(#5E342B).
- 화면의 파랑과 겹치지 않게 위쪽 하늘 영역과 화면 가장자리에 둔다.
- 코드만으로 그리지 않는다. 창 틀과 버튼은 생성한 텍스처를 9-slice로 쓴다.

## 하지 말 것

- 사실적인 비율, 털 질감, 3D 느낌의 음영
- 어둡고 거친 분위기. 심해도 신비로운 쪽으로
- 물속에 따뜻한 색을 넓게 쓰는 것
- 한 화면에 팔레트 밖의 색
- 특정 기존 게임이나 작품의 캐릭터·구도·UI를 닮게 만드는 것

## 에셋을 만들 때

- 단색 배경(물속에 쓰는 색과 겹치지 않는 마젠타 #FF00FF)에 대상 하나씩 생성한다.
- 작게 줄였을 때 남는 형태로 요청한다: 큰 덩어리, 굵은 외곽선, 디테일 최소.
- 생성 → 배경 제거 → 픽셀 격자 정렬(목표 크기 지정) → 이 팔레트 적용 → 1배 크기에서 밝은 배경과 물색 배경 위에 놓고 확인.
