# 그레이박스 플레이 안내

그림과 소리 없이 도형만으로 만든 첫 플레이 판이다. 볼 것은 재미와 손맛이다: 배를 모는 느낌, 이동의 밀도, "조금만 더"와 "돌아가자"의 갈등, 깊이 조준과 줄다리기, 업그레이드까지의 간격.

## 실행

```sh
gf() { uv run -q --project /Users/iyeonsang/Desktop/game/harness/tools gf --project /Users/iyeonsang/Desktop/game/games/cat-angler "$@"; }
gf engine run --record --id play1        # 창이 뜬다. 닫으면 끝. 입력과 상태가 captures/sessions/play1.jsonl 에 남는다
gf engine replay play1 --shot-every 1    # 기록 재생: 반응 없는 입력 후보와 스크린샷
```

저장은 없다. 창을 닫으면 처음부터다. 중간부터 보려면 아래 "디버그 시작"을 쓴다.

## 조작 (키보드만)

| 키 | 육지 | 운항 | 낚시(닻 내림) | 줄다리기 | 패널·카드 |
|---|---|---|---|---|---|
| ← → (A D) | 걷기 | 배 몰기 | (닻을 올리라는 안내) | 물고기를 따라 배를 옮긴다 | 카드 넘기기(→) |
| ↑ ↓ (W S) | | ↓ 로도 닻을 내린다 | 줄 올리기·내리기 | | 고르기 |
| Space (Z) | 줍기·가게 열기·배 타기 | 닻 내리기. 부두·섬 선착장 앞에서는 배 대기 | 미끼 흔들기(주변 물고기를 부른다) | 누르는 동안 감기, 떼면 풀기 | 선택·다음 |
| X (Esc) | | | 닻 올리기 | 줄 끊기(미끼만 잃는다) | 닫기·건너뛰기 |
| Q | 미끼 바꾸기 | 미끼 바꾸기 | 미끼 바꾸기 | | |
| H | 어창 보기(놓아주기) | 어창 | 어창 | | 닫기 |
| C (Tab) | 도감 | 도감 | 도감 | | 닫기 |

화면 아래 줄에 지금 쓸 수 있는 키가 늘 나온다. 하는 일이 없는 키를 누르면 고양이가 귀를 움찔한다(반응 없는 입력을 두지 않으려는 것이다).

## 한 바퀴

1. 항구 왼쪽 끝 채집지에서 약초·곤충·열매를 줍는다(각 4개, 귀항하면 다시 자란다).
2. 미끼 작업대에서 미끼를 만든다. 풀떡밥 4개를 들고 시작한다.
3. 부두에서 Space 로 배를 타고 오른쪽으로 나간다. 새가 도는 어군 표시와 떠다니는 상자·병을 본다(상자와 병은 닿으면 건진다).
4. Space 로 닻을 내리고 ↓ 로 미끼를 물고기 깊이에 맞춘다. 맞는 미끼면 다가와 톡톡 건드리다 문다. 안 맞으면 `?` 를 띄우고 돌아선다.
5. 물면 줄다리기다. 왼쪽 세로 게이지가 장력이다. "버틴다!"에는 Space 를 떼고, "지쳤다!"에는 누른다. 위 빨간 칸에 닿으면 끊어지고, 아래 파란 칸에 오래 있으면 바늘이 빠진다. 큰 물고기가 옆으로 달아나면 ← → 로 따라간다.
6. 어창이 차거나 배가 위험하면 돌아와 부두에서 Space. 어시장에서 팔고, 조선소(수리·배)와 낚시 가게(낚싯대)에서 쓴다.
7. 진행: 낚싯대 2단계(100닢) → 배 2단계(180닢)로 먼바다 → 작은 섬에서 섬꽃 → 낚싯대 3단계(420닢), 배 3단계(650닢) → 용궁 미끼(약초+곤충+열매+섬꽃) → 심해 입구의 소용돌이 자리(2250m) 바닥 근처 132~147m 의 검은 그림자 → 낚아서 부두에 대면 닫는 장면.

배 등급보다 거친 구간에서는 큰 파도를 맞을 때마다 내구도가 깎인다(나룻배로 먼바다: 한 번에 약 6). 0 이 되면 항구로 떠밀려 오고 어창의 절반을 잃는다. 나룻배로 먼바다 가장자리에 잠깐 나가 고등어를 낚고 돌아오는 것은 일부러 열어 둔 모험이다.

화면의 거리(m)는 brief 의 그림과 같은 눈금이다: 부두 306m, 얕은 바다 ~900m, 먼바다 ~1800m, 심해 입구 ~2400m. 암초 1200m, 작은 섬 1440m(선착장은 왼쪽 기슭), 난파선 1640m, 소용돌이 자리 2250m.

## 디버그 시작

`gf engine` 명령은 게임에 인자를 넘기지 못하므로 환경 변수 `CA_START` 를 쓴다. Godot 을 직접 띄울 때는 `-- --start=...` 도 된다. 값은 `키=값` 을 쉼표로 잇는다. 주면 여는 장면을 건너뛴다.

| 키 | 뜻 | 예 |
|---|---|---|
| `coins` | 가진 돈 | `coins=500` |
| `rod`, `boat` | 장비 단계 1~3 | `rod=2,boat=2` |
| `x` | 이 거리(m, 화면의 눈금과 같다)의 바다 위에서 시작. 없으면 항구 | `x=1010` |
| `baits` | 미끼 네 종류를 이만큼씩 | `baits=8` |
| `legendbait` | 용궁 미끼만 따로 | `legendbait=1` |
| `mats` | 재료 네 종류를 이만큼씩 | `mats=3` |
| `bait` | 처음 고른 미끼(herb/bug/berry/legend) | `bait=berry` |
| `hold`, `caught` | 어창에 실린 물고기, 도감에 기록된 어종(`+` 로 잇는다) | `hold=legend`, `caught=anchovy+scad` |
| `dur` | 배 내구도 | `dur=8` |
| `intro` | `1` 이면 여는 장면을 보여 준다 | `intro=1` |

```sh
CA_START="coins=300,rod=2,boat=2,baits=6,x=1010" gf engine run --record --id open-sea     # 먼바다부터
CA_START="rod=3,boat=3,baits=8,legendbait=2,x=2200" gf engine run --record --id legend    # 전설의 심해어 앞에서
CA_START="x=950,baits=6" gf engine run --record --id risky                                # 나룻배로 먼바다 가장자리
godot --path . -- --start=coins=999,rod=3,boat=3                                          # 하네스 없이
```

같은 기록을 재생할 때도 같은 `CA_START` 를 줘야 한다.

## 플레이하면서 볼 것

brief 의 "사람이 판정할 것"을 해 볼 일로 옮긴 것이다.

| 판정 | 해 볼 것 |
|---|---|
| 배를 모는 느낌, 무게 | 최고 속도에서 손을 떼고 미끄러지는 거리를 본다. 반대로 꺾어 본다. 먼바다(`x=1010`)와 심해 입구(`x=2000,boat=3`)에서 파도를 탈 때 기울고 떠오르는 것이 기분 좋은가, 멀미 나는가. 단계별 배의 속도 차이가 느껴지는가 |
| 이동이 지루하지 않은가 | 부두에서 심해 입구 끝까지 한 번에 가 본다(큰 어선으로 약 40초). 빈 화면이 이어지는 곳이 있는가. 상자와 병을 건지는 것이 손을 심심하지 않게 하는가, 귀찮은가. 어군 표시를 보고 자리를 고르게 되는가 |
| "조금만 더"와 "돌아가야 하나" | 나룻배로 먼바다 가장자리(900~1000m)에 나가 본다. 파도를 몇 번 맞고 돌아서게 되는가. 내구도 막대가 판단에 쓰이는가. 어창이 6칸일 때 싼 물고기를 놓아주고 비싼 것을 싣게 되는가(H) |
| 깊이 조준 | 넙치(바닥 23~30m)와 멸치(2~10m)를 번갈아 노려 본다. 줄이 너무 빠르거나 느린가. 물고기 앞에 놓는 일이 답답한가. 낚은 뒤 줄이 수면으로 돌아오는 것이 깊은 곳에서 번거로운가 |
| 줄다리기 | 넙치(나룻배 낚싯대로는 힘이 같다), 방어, 곰치, 전설 순으로 해 본다. "곧 버틴다" 예고(0.38초)가 반응하기에 충분한가. 일부러 계속 눌러 끊어 보고, 계속 떼어 빠뜨려 본다: 왜 졌는지 알 수 있는가. ← → 따라가기가 의미 있는가 |
| 다음 업그레이드까지의 간격 | 업그레이드마다 몇 번 출항했는지 센다. 봇(얕은 바다에서는 모험하지 않는다)은 낚싯대 2단계까지 2번, 배 2단계까지 4번 더, 낚싯대 3단계까지 3번, 배 3단계까지 3번, 그 뒤 2번에 끝냈다(모두 14번, 게임 시간 약 27분). 배 2단계 전의 얕은 바다 4번이 가장 길다. 지루해지는 지점이 어디인가 |
| 전설 어종이 정점인가 | `CA_START="rod=3,boat=3,baits=8,legendbait=2,x=2200"` 로 바로 해 본다. 봇은 한 번도 실수하지 않고 약 36초 걸린다. 길이와 긴장이 맞는가 |
| 귀여움, 소리 | 이 판에서는 판정할 수 없다(도형뿐이고 소리가 없다) |

플레이 뒤에 세 가지를 알려 주면 된다: ① 한 번 더 나가고 싶었나 ② 조작에서 거슬린 순간 ③ 헷갈린 것.

## 알려진 거친 부분

- 그림, 소리, 이야기 컷의 그림이 없다. 여는 장면과 닫는 장면은 글 카드다.
- 저장이 없다.
- 낚을 때마다 줄이 수면으로 돌아와 깊은 곳에서는 다시 내리는 데 5~6초가 든다.
- 닻을 내린 뒤에는 배를 옮길 수 없다. 물고기가 멀면 닻을 올리고 다시 자리를 잡아야 한다.
- 가게 주인은 색 덩어리이고 대사는 한 줄뿐이다.
- 수리는 돈이 든다(2 내구도에 1닢). 난파하면 내구도 절반으로 돌아온다.
- 큰 파도는 피할 수 없고 배 등급으로만 버틴다.
- 미끼가 남아돈다(채집 한 번에 재료 12개, 한 출항에 쓰는 미끼는 6~14개). 미끼는 "어떤 어종이 무는가"만 정하고 수량의 압박은 거의 없다.
- 얕은 바다에는 어군 표시가 드물 때가 있다(바다 전체에 6개를 유지한다). 그럴 때는 떠다니는 물건이 빈자리를 채운다.
- 전설의 심해어는 한 마리다. 싣고 오다 난파해 잃으면 소용돌이 자리에 다시 나온다.
- 글꼴은 Godot 기본 글꼴과 시스템 한글 글꼴이라 320×180 에서 거칠다.
